1) Weekly Command Center (Owner View)

Scope

Create a weekly “what matters now” layer for each tenant.

Features

• Weekly snapshot cards:
• Top 3 wins
• Top 3 risks
• Critical unresolved alerts
• Locations needing intervention
• “This Week’s Priorities” list auto-generated from:
• trend deterioration
• threshold misses
• low scorecard outcomes

Endpoints

• GET /api/tenants/:tenantId/weekly-command-center
• POST /api/tenants/:tenantId/weekly-command-center/refresh

UI

• /command-center page
• Priority list with direct “Create Action” buttons

2) Action Management + Accountability

Scope

Turn identified issues into trackable execution work.

Features

• Create actions from alerts, trends, scorecards, or manual
• Assign owner + due date + location + linked metric
• Status lifecycle: open, in_progress, blocked, done
• Weekly check-in notes on each action
• Overdue highlighting and escalation flags

Endpoints

• GET /api/tenants/:tenantId/actions?status=&owner=&locationId=&overdue=
• POST /api/tenants/:tenantId/actions
• PUT /api/tenants/:tenantId/actions/:actionId
• POST /api/tenants/:tenantId/actions/:actionId/checkins

Data model additions

• actions
• action_checkins

UI

• /actions page (kanban + list toggle)
• Action detail drawer with timeline/check-ins
